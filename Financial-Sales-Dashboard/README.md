# Financial Sales Dashboard – Power BI

## 📊 Project Overview

This project is an interactive Financial Sales Dashboard built using Microsoft Power BI.

The dashboard analyzes sales performance, profitability, cost of goods sold, units sold, and profit margins across different countries, products, segments, and time periods.

The objective of this project is to transform raw financial sales data into an interactive dashboard that can help stakeholders monitor business performance and identify key trends.

---

## 🎯 Business Objectives

The dashboard was developed to answer questions such as:

- What are the total sales and total profit?
- How many units have been sold?
- What is the overall profit margin?
- How are sales changing over time?
- Which countries generate the highest sales?
- Which products contribute the most to sales?
- How does performance vary across customer segments?
- What is the relationship between sales, COGS, and profit?
